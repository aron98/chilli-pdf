chilli-pdf — searchable-PDF converter
====================================

This archive contains everything chilli-pdf needs. No installation, no
administrator rights, no internet connection, and no other software is
required.

Quick start
-----------
1. Unpack the archive (keep the files together).
2. Run the chilli-pdf executable:
   - Windows:  double-click chilli-pdf.exe
   - macOS:    open the archive's folder in Finder, then click chilli-pdf
   - Linux:    run ./chilli-pdf in a terminal

On first launch chilli-pdf prepares its bundled components (PDF engine,
OCR engine, and language models) in your personal application-data
directory. That is normal, happens once per version, and needs no
permissions you do not already have. After that it works fully offline.

Supported OCR languages: English and Hungarian.

Verifying the download
----------------------
Check the archive against the SHA256SUMS file published next to it on
the releases page (sha256sum on Linux/macOS, Get-FileHash on Windows).
